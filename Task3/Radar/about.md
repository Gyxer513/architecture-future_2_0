# Как пользоваться радаром

Верхняя панель позволяет фильтровать технологии по статусу — **Adopt**, **Trial**, **Assess**, **Hold** — и по quadrant.  
Каждый элемент на круге — технология с описанием, размещённая в соответствующем квадранте.

Примеры:
- *Data Mesh* — новая японская модель роста данных (quadrant: Methods & Patterns).
- *Iceberg* — репозиторий табличных данных «Lakehouse».

Чтобы добавить новые элементы, создайте новый каталог `radar/<год-месяц-день>/` и положите туда `.md`‑файлы с YAML‑параметрами.  
После чего — `npm run build`.
